学习辅助系统使用指南

基于 AI 多智能体协作的个性化学习平台。7 个专业 Agent 覆盖学习规划、知识讲解、练习测评、错题复盘全流程，助你高效达成学习目标。

快速上手 查看功能

功能概述

7 个专业 Agent + 全链路学习闭环，覆盖从规划到复习的完整学习周期

学习规划

Planner Agent 根据你的目标和时间，制定分阶段、可量化的学习计划。

知识讲解

Expert 与 Partner Agent 联手提供专业的知识解答、资料推荐和深度讲解。

智能出题

Quizzer Agent 根据你的掌握程度自适应生成试题，精准评估学习效果。

错题复盘

Reviewer Agent 分析错题模式，定位薄弱知识点，反馈给规划 Agent 优化后续学习。

文件上传分析

支持 PDF、Word、TXT 及代码文件上传，上传后可针对文件内容提问并导出 Word 文档。

备考指导

Examiner Agent 提供考试策略、模拟面试和备考规划，助你从容应对各类考试。

快速上手

三步开始你的智能学习之旅

1

注册账号

打开系统后，点击"注册"标签，填写用户名和密码即可创建账号。建议填写昵称和邮箱以便后续找回密码。

密码至少 6 个字符，建议包含字母和数字
2

选择 Agent

登录后，在左侧边栏的"Agent 选择"面板中选择适合当前需求的 Agent 角色，或保持默认的"自动识别"让系统智能匹配。

推荐首次使用选择"自动识别"，系统会根据你的问题自动路由
3

开始对话

在底部输入框输入你的问题，按 Enter 发送。系统支持实时流式回复，也可以上传文件后再提问。

Shift+Enter 换行，Enter 发送消息

操作指南

掌握各项核心功能的使用方法

文件上传与分析

  1. 点击输入框左侧的 📎 附件按钮，或直接将文件拖拽到聊天区域
  2. 选择要上传的文件（支持 PDF、Word、TXT、Python、Java 等格式，最大 10MB）
  3. 上传进度条会实时显示上传状态，完成后文件标签会出现在输入框上方
  4. 在输入框中输入与文件内容相关的问题，按 Enter 发送
  5. 系统会基于文件内容生成回答，并自动生成可下载的 Word 文档
支持格式：PDF / Word (.docx, .doc) / TXT / .md / .py / .java / .cpp / .js / .ts / .html / .css / .json / .xml / .yaml / .csv

Agent 角色选择

点击左侧边栏的 "Agent 选择" 面板，可以看到 7 种专业 Agent：

Agent适用场景示例问题
自动识别不确定用哪个任意问题，系统自动路由
学习规划师制定学习计划"帮我制定一个 30 天的 Python 学习计划"
学习专家获取知识讲解"推荐适合初学者的机器学习课程"
学习伙伴日常答疑解惑"什么是 RESTful API？"
出题官练习与自测"给我出 5 道数据结构的选择题"
复习助理错题整理分析"帮我分析最近的错题，找出薄弱知识点"
考试指导备考规划"考研计算机专业如何高效复习？"

对话管理

  • 新建对话：点击侧边栏"历史对话"旁的 + 按钮，创建新的对话线程
  • 切换对话：点击历史对话列表中的任意对话，加载该对话的完整消息记录
  • 删除对话：点击对话旁的删除按钮，移除不再需要的对话
  • 删除单条消息：鼠标悬停在用户消息上，点击"删除"按钮可移除该问答对

文档导出

AI 回复支持导出为 Word 文档：

  • 每条 AI 回复消息下方都有 "下载 Word" 按钮
  • 点击后自动下载格式化的 Word 文档，包含问题、回答和生成时间
  • 文件上传后提问的回答也会自动生成可下载的 Word 文档

主题切换

  • 主题切换：点击侧边栏的"主题"按钮，在明暗模式之间切换，系统会记住你的偏好

常见问题

FAQ

文件上传后无法提问怎么办？

请确认以下几点：

  • 文件已成功上传（输入框上方出现文件标签，显示文件名）
  • 文件格式在支持范围内（PDF、Word、TXT、代码文件等）
  • 文件大小不超过 10MB
  • 在输入框中输入与文件相关的问题后再发送
为什么 AI 回复有时会比较慢？

AI 回复速度取决于以下因素：

  • 选择的 Agent 类型（如 Planner 需要更长的推理时间）
  • LLM 服务商的当前负载情况
  • 是否启用了 Web 搜索（Expert Agent 需要联网检索）
  • 消息历史长度（更长的对话历史需要更多处理时间）

通常回复时间在 3-30 秒之间，如果超过 120 秒系统会自动超时并提示重试。

对话历史能保存多久？

对话历史通过 MySQL 数据库持久化存储，理论上可以永久保存。系统会自动管理：

  • 单对话最多保留 200 条消息（超出后自动裁剪旧消息）
  • 内存中的对话缓存超过 24 小时未活跃自动清理
  • 磁盘上的对话历史会定期保存，服务重启后自动恢复
支持哪些文件格式？文件大小有限制吗？

支持格式：PDF、Word (.docx/.doc)、TXT、Markdown、以及 Python/Java/C++/JavaScript/TypeScript/HTML/CSS/JSON/XML/YAML/CSV 等代码文件。

大小限制：单个文件最大 10MB。超过限制的文件会被拒绝并提示错误信息。

可以同时上传多个文件吗？

目前系统支持单次上传一个文件。如需分析多个文件，可以依次上传，上传后的文件会以标签形式显示在输入框上方。当前版本中，提问时会将第一个上传文件的内容作为上下文发送给 AI。

系统需要联网吗？

系统核心功能需要联网访问 LLM API（如 OpenAI、ModelScope 等）。如果配置了本地 LLM（如 Ollama），则可以在离线环境下使用。Web 搜索功能需要额外配置 SerpAPI 密钥。

忘记密码怎么办？

当前版本暂不支持自主密码找回功能。如需重置密码，请联系系统管理员在数据库层面进行操作。建议注册时填写邮箱，以便后续版本支持邮箱找回功能。

注意事项

使用前请仔细阅读以下重要提示

安全提醒

  • 请勿上传包含个人隐私或敏感信息的文件
  • API 密钥等敏感信息请妥善保管，不要分享给他人
  • 生产环境部署时务必启用 API_AUTH_ENABLED=true
  • 定期修改密码，使用强密码保护账号安全

使用建议

  • 建议使用现代浏览器（Chrome/Firefox/Edge 最新版）
  • 首次使用建议从"自动识别"Agent 开始，熟悉后再尝试特定 Agent
  • 文件上传后建议先提问，不要直接发送空白消息
  • AI 生成的回答仅供参考，重要决策请交叉验证

技术限制

  • 文件上传后服务重启会导致文件 ID 失效，需重新上传
  • Word 文档中文字体偶有排版偏移，属 python-docx 已知限制
  • 前端直接通过 file:// 协议打开可能存在跨域问题，建议使用 http.server 托管
  • 大文件（接近 10MB）上传时进度条显示 0-90%，剩余时间依赖服务器处理

最佳实践

  • 提问时尽量具体明确，包含上下文信息以获得更精准的回答
  • 善用对话管理功能，为不同学习主题创建独立对话
  • 使用"出题官"Agent 定期自测，巩固学习效果
  • 将重要的 AI 回答导出为 Word 文档保存到本地
