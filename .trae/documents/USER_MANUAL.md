# 学习辅助系统 — 使用手册

## 1. 系统简介

学习辅助系统是一个 AI 驱动的智能学习平台，提供学习规划、资料推荐、答疑解惑和测验生成等服务。系统内置多个专业 Agent，可根据你的问题自动选择合适的 AI 助手。

## 2. 快速开始

### 2.1 访问系统

在浏览器中打开系统地址（如 `http://localhost`），即可看到登录页面。

### 2.2 注册账号

1. 点击登录页面的 **"注册"** Tab
2. 填写以下信息：
   - **用户名**（必填，至少3个字符）
   - **昵称**（可选，用于个性化显示）
   - **邮箱**（可选）
   - **密码**（必填，至少6个字符）
   - **确认密码**（与密码一致）
3. 点击 **"注册"** 按钮

### 2.3 登录

1. 在登录 Tab 中输入用户名和密码
2. 点击 **"登录"** 按钮
3. 登录成功后自动进入主界面

## 3. 主界面介绍

主界面分为左侧**侧边栏**和右侧**聊天区域**。

### 3.1 侧边栏功能

| 模块 | 功能 | 操作 |
|------|------|------|
| 用户信息 | 显示昵称和用户名 | 自动加载 |
| 个人设置 | 编辑昵称、邮箱、学习水平、目标领域、可用时间、学习偏好 | 点击展开 → 修改 → 保存 |
| 修改密码 | 修改登录密码 | 输入原密码和新密码 → 提交 |
| Agent 选择 | 选择 AI 助手角色 | 单选切换 |
| 快捷操作 | 一键生成学习计划 / 退出登录 | 点击按钮 |
| 测验生成 | 生成自测题目 | 输入知识点 → 选择数量 → 生成 |

### 3.2 聊天区域

- **输入消息**：在底部输入框输入问题，按 Enter 发送（Shift+Enter 换行）
- **查看回复**：AI 回复以流式方式逐字显示，支持 Markdown 格式
- **Agent 标签**：每条 AI 回复下方显示处理该消息的 Agent 名称

## 4. Agent 角色说明

| Agent | 角色 | 适用场景 |
|-------|------|----------|
| 自动识别 | 系统自动选择最合适的 Agent | 日常使用，推荐 |
| 学习规划师 | 制定学习计划和时间安排 | "帮我制定 Python 学习计划" |
| 学习专家 | 深入解答专业知识 | "解释一下快速排序算法" |
| 学习伙伴 | 提供学习建议和鼓励 | "学习没动力怎么办" |
| 出题官 | 生成练习题和测验 | "出几道 SQL 查询题" |
| 复习助理 | 帮助复习和总结 | "帮我总结机器学习要点" |
| 考试指导 | 考试技巧和备考建议 | "英语六级怎么备考" |

## 5. 个人设置

### 5.1 学习水平

- **入门**：刚开始学习
- **中级**：有一定基础
- **高级**：熟练掌握
- **专家**：精通领域

### 5.2 学习偏好

- **综合学习**：多方式结合
- **视觉学习**：图表、视频
- **听觉学习**：音频、讲解
- **文本阅读**：文档、书籍
- **动手实践**：编程、实验

### 5.3 可用时间

设置每周可投入的学习时间（1-80小时），系统会据此推荐合适的学习计划。

## 6. 快捷操作

### 6.1 一键学习计划

点击侧边栏 **"📋 计划"** 按钮，系统自动切换到"学习规划师" Agent 并发送"帮我制定一个学习计划"。

### 6.2 测验生成

1. 展开侧边栏 **"🧪 测验"** 面板
2. 输入知识点（如"Python基础"）
3. 拖动滑块选择题目数量（1-10道）
4. 点击 **"🎯 生成测验"** 按钮

## 7. 密码修改

1. 展开侧边栏 **"🔒 修改密码"** 面板
2. 输入原密码
3. 输入新密码（至少6位）
4. 确认新密码
5. 点击 **"🔑 修改密码"**

## 8. 退出登录

点击侧边栏底部的 **"🚪 退出"** 按钮，在确认弹窗中点击 **"确定退出"**。

## 9. 移动端使用

在手机或平板浏览器中打开系统，界面会自动适配：

- 侧边栏默认隐藏，点击左上角 ☰ 按钮展开
- 输入框和按钮大小自动适配触屏操作
- 支持系统暗色模式（跟随设备设置）

## 10. 常见问题

**Q: 无法发送消息？**
A: 请检查后端服务是否正常运行（`http://localhost:8000/health`）。

**Q: 回复显示乱码？**
A: 请使用 Chrome/Firefox/Safari/Edge 最新版本浏览器。

**Q: 如何切换 Agent？**
A: 在侧边栏"Agent 选择"面板中点击对应的 Agent 即可切换。

**Q: 聊天记录会保存吗？**
A: 聊天记录保存在当前浏览器会话中，关闭标签页后会清除。登录状态（Token）会持久保存。
